# TGMS Dammannapet – School Website

A fast, mobile-friendly static website for **TGMS Dammannapet** built with plain HTML, CSS and JavaScript. No build tools or frameworks needed, so it can be hosted free on **GitHub Pages**.

## Pages

| File | Page |
|---|---|
| `index.html` | Home (hero, highlights, principal's message, latest notices) |
| `about.html` | About, vision/mission, school details, staff |
| `academics.html` | Classes, subjects, teaching approach, activities |
| `admissions.html` | Admission steps, documents, enquiry form |
| `facilities.html` | Campus facilities |
| `gallery.html` | Photo gallery with lightbox |
| `notices.html` | Notice board with filters |
| `contact.html` | Address, map, contact form |

## Folder structure

```
tgms-dammannapet/
├── index.html … contact.html
├── css/style.css          # all styling (colours are CSS variables at the top)
├── js/data.js             # EDIT THIS: school name, phone, email, notices, gallery list
├── js/main.js             # header, footer, notices, gallery, forms
├── assets/images/         # logo.svg, favicon.svg and your photos
├── .nojekyll
└── README.md
```

## Customise in 5 minutes

1. Open `js/data.js` and replace the **address, phone, email, office hours**.
2. Add your real **notices** (newest first).
3. Copy school photos into `assets/images/` and list them under `gallery` in `js/data.js`.
4. Replace the placeholder text in the HTML pages (principal's message, staff names, class list, year of establishment, UDISE code, facilities).
5. Replace `assets/images/logo.svg` with the official school logo (keep the file name, or update the path in `js/main.js`).
6. To change colours, edit the variables at the top of `css/style.css`.

> The header and footer are generated by `js/main.js` from `js/data.js`, so menu and contact changes need to be made only once.

## Preview on your computer

Just double-click `index.html`, or run a local server:

```bash
python3 -m http.server 8000
# open http://localhost:8000
```

## Publish with GitHub Pages

```bash
cd tgms-dammannapet
git init
git add .
git commit -m "Initial TGMS Dammannapet website"
git branch -M main
git remote add origin https://github.com/<your-username>/<your-repo>.git
git push -u origin main
```

Then on GitHub: **Settings → Pages → Build and deployment → Source: Deploy from a branch → Branch: `main` / `(root)` → Save.**
After a minute the site is live at `https://<your-username>.github.io/<your-repo>/`.

### Custom domain (optional)
Add your domain under **Settings → Pages → Custom domain**, then create the DNS records GitHub shows. GitHub will add a `CNAME` file for you.

## Notes

- All links are relative, so the site works at a sub-path such as `/<your-repo>/`.
- The contact and admission forms open the visitor's email app (`mailto:`) because GitHub Pages has no server. For stored submissions, connect a free form service such as Formspree or Google Forms.
- Placeholder text and sample notices are clearly marked – please replace them with verified school information before publishing.
